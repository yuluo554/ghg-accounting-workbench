# data/ 数据台账

> 规则（ai-tool-project-sprint 阶段 1）：每份数据登记来源与许可；规范条目挂出处 + status（`verified`/`pending`）；程序化自制带真值数据是核心资产（固定输入可复现）。`_private/` 目录不入仓。
> 纪律：**未挂原文核对不得落库/生效/进入计算路径**；搜索摘要一律不采信，数值以官方原文/标准页面直连核对。

### 数据态说明（M4）

- 40 份规则包由生成器产出，**逐条挂官方原文核对**：通则元数据（发布/实施日期、代替关系、有效性）、
  排放源纳入判定（四行业指南 §5.2）、公式条款、行业缺省因子与氧化率系数、配额方法学与基准值。
- **门控按计算路径分作用域**（`plan/06` D1-1）：核算 / 配额 / 校核三条路径各查各的块，互不牵连。
  当前：核算路径 **38/40 可通过**（仅 2026 年度发电被拦，其碳氧化率已改由因子库取值，而因子库站点 WAF 阻断未能摘录）；
  配额路径与校核路径 **40/40 可通过**（M3 起：配额方法学/参数已核对；校核阈值为 M3 工程定值）。
- **基准验收门槛随 manifest 下发**（`plan/06` D4-1）：`manifest.bench.targets` 载五项门槛
  （自洽率 / 一致率 / 命中率 / 误报率 / 运行时长上限）。门槛是**数据不是代码**——与零政策字面量同一条纪律，
  基准层只读、不内联默认值（缺失即 `BenchConfigError`，退出码 2）。
- **误报对照集由真值库显式声明**（`plan/06` D4-4）：`expected.json` 的 `controls` 块逐条列出"应零命中"的
  干净档案（含同比未变化的 `steel-2024-yoy-clean`）与"命中但可降级"的档案；基准层不自行挑选对照档案。
- **配额参数三态**（`plan/06` D3-2）：`verified`（发电 2025/2026 基准值、强度系数分段常数）/ 
  `input_required`（三行业"行业平衡值"仅平台可查、发电"调峰修正系数"随机组而异 → 试算层运行时显式索取，
  缺失即退出码 2，**绝不静默取 0/1**）/ `pending`（门控拦截）。
- **校核阈值为工程判据**（`plan/06` D3-1）：`quality.thresholds` 四项由 M3 定值并标 `verified`，
  规则包内 `clause.code = null` 且注明"工程筛查阈值（非政策数值）"，与政策数值严格区分。
- 生成器为**唯一写入者**：产物禁手改；改体例走 `tools/gen_*.py` 整目录重生成，
  配"再生成逐字节一致"守门测试（`code/tests/test_m1_data.py`）。
- `units.json` 单独标注 `verified`：单位换算因子属**定义性关系**，不是需要发文核对的政策数值（决策见 plan/06 D0-8）。

## 三、合成数据纪律

- **假企业白名单**：合成企业统一使用虚构名称（"示例钢铁（合成）有限公司"等，含「（合成）」后缀）
  + 虚构统一社会信用代码（保留测试号段 `90000000…SYN`）；不得使用任何真实企业名称、产能或排放数据。
- **植入真值**：合成企业档案由 `tools/gen_synthetic.py` 生成时同时产出**期望核算结果**
  （逐源分解 + 汇总），真值随档案入库，引擎以独立实现路径对账（`test_m1_data.py` / `test_m2_engine.py` 双路对账）。
- **M2 算例扩充**：真值库含显式单位换算算例（活动数据以 `kg` 录入 → 引擎须换算到 `t` 口径后与真值一致）、
  因子优先级算例（实测 / 官方因子库覆盖行业缺省），以及失败路径用例（缺应核算源 / 混算 / 因子三层皆无 / 坏格式）。
- **M3 算例扩充**：真值库新增（1）**四类校核异常各 1 例**——单位错配（`steel-2024-bad-unit`）、
  量级异常（`steel-2024-magnitude`）、跨年突变（`steel-2024-yoy-jump`，配同比未变化的**误报对照** `steel-2024-yoy-clean`）、
  比强度越界（`steel-2024-intensity`）；（2）**配额方法学算例**——发电基准法（`power-2025`，调峰修正系数由算例显式给出）
  与三行业强度系数法（`steel-2024`，行业平衡值由算例显式给出），真值按方案原文公式（`A=Qe×Be×Ff`、`A=E×(1+α)`）独立算出。
  为支持比强度校核与配额试算，四行业 2024 主档案与 `steel-2023` 附**产量**（`output`，按目标比强度反推，落规则包强度区间中部）。
- **M4 对照集声明**：真值库新增 `controls` 块，显式声明基准要用的**误报对照集**——
  `quality_clean`（8 个应零命中的干净档案，含四行业主档案、实测因子档案、旧版通则档案）、
  `quality_yoy_clean`（同比活动数据逐位相同 → 跨年突变检查不得命中）、
  `quality_non_error`（kg 录入可显式换算 → 单位口径不一致只报 `warning`，不得升为 `error`）。
  基准层只读该声明，**不自行挑选对照档案**（否则等于"基准自选考卷"，口径会随实现漂移，见 plan/06 D4-4）。
- **因子来源标注**：合成档案使用规则包的行业缺省因子（`factors.industry_default_values`，逐条挂指南条款号）；
  因子优先级算例中的实测/官方库因子为**合成占位值**（`source` 显式标注，数值取行业缺省值的一半便于断言），
  属**机制验证**而非真实因子入库；不得进入基准真值。
- **配额外部输入的合成值**：行业平衡值（BP）与调峰修正系数属"平台可查 / 随机组而异"的真实外部输入，
  算例给出的是**合成占位值**（`2.1` / `0.97`），仅用于验证方法学分支与对账，不代表任何真实配额参数。
- **可复现**：生成器使用自研 counter-mode SHA-256 确定性 RNG（**禁 stdlib random**），固定 seed
  `ghg-synthetic-2026-10-13`；同一输入必得同一输出，产出物 sha256 留档（`data/truth/expected.json`）。

## 四、法律与许可口径

- 规则包 JSON 中的标准/条款信息以"标准号 + 条款号 + 要点"形式呈现（规避全文转载），原文以官方页面为准；
- data/knowledge/raw/ 快照为官方公文与标准页面（著作权法第五条官方文件不适用版权保护）；
- 合成数据与真值库为本项目自制（固定输入可复现），MIT 许可随仓库发布。
