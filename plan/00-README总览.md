# 10-13-ghg-accounting-workbench 项目计划总览

**项目**：企业温室气体排放核算与报告工作台（组织碳核算工具，Windows 桌面 + CLI 双形态，GB/T 32150 新旧双标尺 × 年度 × 行业三维版本化规则集）
**方法论**：ai-tool-project-sprint（条款库 + 版本化规则集 + 官方因子库 + 合成真值基准 + 报告导出 + 离线交付）
**项目系列**：同系列第 13 题（前作名称与业务领域按脱敏纪律不入公开仓，见 [06-决策记录.md](06-决策记录.md) D00-9）
**命名约定**：本地目录 `10-13-ghg-accounting-workbench`（`10-13` = 2026-10-13 日期标签）；**GitHub 仓库名 = `ghg-accounting-workbench`（纯净名，去日期前缀）**，署名 `yuluo554`（LICENSE/pyproject 一致）。
**定位宣言（v1）**：把"活动数据 × 排放因子 → 可核证报告"整条链做成**可复现、可溯源、跨标准版本不混算**的本地工具——LLM 聊天给不了持久规则库、逐数字溯源与全量枚举校核，本工具是碳合规申报前的质量防线。
