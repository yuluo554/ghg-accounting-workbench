## 一、项目介绍

全国碳排放权交易市场完成发电行业起步后，**钢铁、水泥、铝冶炼三行业已纳入扩围**，2026 年度三行业配额总量与分配方案已于 2026-09-02 落地；同时 **GB/T 32150-2025《工业企业温室气体排放核算和报告通则》于 2025-12-31 发布、2026-07-01 实施**，替代 GB/T 32150-2015（2015 版已置废止），企业正处在**新旧核算标准切换期**。欧盟 CBAM 亦已于 2026-01-01 进入正式征收期。企业侧的真实痛点是：核算边界如何圈定、活动数据×排放因子如何逐项留痕、跨年度/跨行业规则差异如何不错用、核查时如何证明"每一个数字都能追到来源"。

现有开源生态中，通用 LCA 引擎（openLCA 等）已充分竞争，但**中国国标口径（GB/T 32150）的组织碳核算开源实现近乎空白**（GitHub 中文"温室气体 核算"检索仅 1 个 1-star 项目，GB/T 32150 口径实现几乎为零）。本项目要求开发一款**企业温室气体排放核算与报告工作台**：以 **GB/T 32150 新旧双标尺 + 分行业规则包** 为规则内核，**官方排放因子库（第二版）** 为数据底座，实现"活动数据录入 → 排放量确定性计算 → 数据质量校核 → 可核证报告导出"的本地闭环，核心特色是**版本化规则集**（沿用系列食品标签/个税计算器的 versioned ruleset 模式，扩展为"国标版本 × 年度 × 行业"三维规则包），每个计算结果旁挂条款与因子来源。

## 二、任务要求

> 首期范围限定为 **发电、钢铁、水泥、铝冶炼四个行业 + GB/T 32150 新旧两版通则**，其余行业留扩展。全部模块遵循"**未挂原文核对不得落库/生效/进入计算路径**"的确定性纪律。

### 1）核算边界与排放源识别引擎

- 按 GB/T 32150-2025（新）与 GB/T 32150-2015（旧）分别定义核算边界口径（设施/组织边界、排放源分类：化石燃料燃烧、过程排放、净购入电力热力、固碳产品等）；
- 输入企业设施清单 → 输出应核算排放源清单（带"为什么纳入"的条款依据）；
- **双标尺差异提示**：新旧版对某排放源的纳入/口径差异自动标出（如新增/调整源），这是切换期最实用的功能。

### 2）活动数据 × 排放因子确定性计算引擎

- 按国标公式树逐条实现：排放量 = 活动数据 × 排放因子 × 氧化率系数（分排放源类型）；
- 支持**多层级排放因子来源优先级**：①企业实测因子 ②官方排放因子数据库（第二版，data.ncsc.org.cn）③行业缺省值；每一层来源在结果中留痕；
- 全程 **Decimal 精度**、单位换算显式化（t/J/Nm³/MWh 等），禁止字面量硬编码（因子与参数一律从规则包读取）。

### 3）三维版本化规则集（工程亮点）

- 规则包按 **`通则版本 × 年度 × 行业`** 三维组织：GB/T 32150-2015 / 2025 两版通则 + 2022-2026 各年度 + 四行业分行业核算与报告指南（如 CETS—AG 系列）；
- 每次核算在报告头显式声明"采用的规则包坐标"（哪版通则、哪年、哪行业），**跨版本混算即报错**；
- 规则包 JSON 化，每条数值/系数挂文号或标准号与 status（`verified`/`pending`），未核对不得生效（门控与系列个税计算器同构）。

### 4）数据质量校核层（亮点）

- **活动数据合理性检查**：单位一致性、量级异常、跨年度突变、与产量/产能的比强度合理性（如吨钢综合能耗区间）；
- **因子适用性检查**：所选因子与排放源类型/行业/年度是否匹配（防止错用缺省值）；
- **边界完整性检查**：申报排放源是否覆盖规则包要求的全部应核算源；
- 输出**校核问题清单**（分级：错误/警告/提示），每条挂规则依据。

### 5）与碳市场衔接的配额试算模块（应用亮点）

- 输入企业产量/产能等参数 → 按**行业配额分配方案**（基准线法/历史强度法等）试算年度配额，与核算排放量对比给出履约缺口预判；
- 配额方法学按行业规则包配置（发电/钢铁/水泥/铝冶炼方法不同），**方法学切换即切换公式**；
- 免责红线：试算结果仅供内部预判，正式配额以主管部门核定为准。

### 6）可核证报告导出（交付物进入工作流）

- 一键导出**核算报告**（含核算边界、逐排放源明细表、因子来源表、核算过程、依据清单），格式支持 **Markdown + XLSX/CSV**；
- **数据溯源表**：报告每个数字可回溯到"活动数据来源 → 因子来源 → 规则条款"，供第三方核查对照；
- 报告头固定输出规则包坐标 + 生成时间 + 工具版本，保证可复现。

### 7）内置评测基准（零 API 依赖）

- **规则自洽基准**：新旧通则 × 四行业 × 多年度规则包的公式与系数枚举自洽性扫描；
- **因子库一致性基准**：因子表内部一致性（同源因子跨年变化、单位换算往返）；
- **边界与异常用例基准**：边界识别、跨版本混算拦截、数据质量校核命中率——程序化构造带真值的合成企业档案，零 API 依赖可重复，指标写进 README。

## 六、边界与非目标

- **不做**：产品碳足迹（PCF）核算（属 GB/T 24067，另题）；不做碳交易撮合/报价；不做 CCER 项目开发；不做企业实测因子的实验室检测；不对接生态环境部申报系统接口。
- **首期范围**：发电/钢铁/水泥/铝冶炼四行业 + 新旧通则两版；其余行业留扩展项。
- **合规红线**：全本地核算存储、零上传；**免责声明强制**：核算与配额试算结果仅供内部参考，正式数据以主管部门核定/核查机构结论为准；规则包未挂原文核对（status=pending）不得进入计算路径。
- **数据纪律**：官方排放因子逐条登记来源 URL 与版本；合成企业档案与真值自建，**不得使用真实企业数据**；缺省值来源不明不得作为默认因子。
- **品牌隔离**：不复制姊妹项目代码；文档不提其余项目业务领域。
