## 二、豁免口径（零政策字面量门禁的白名单）

`tools/check_zero_literals.py` 扫描范围与豁免（**必须写死，否则门禁刷屏后被运维性忽略**）：

| 类别 | 处置 |
|---|---|
| 扫描范围 | **仅** `code/src/ghg/**/*.py`（含 docstring 与注释）——引擎与前端源码 |
| **不扫**生成器 | `tools/gen_rulesets.py` / `tools/gen_synthetic.py` **不在扫描范围**：生成器是数据文件的生产者（真相源），必然持有模板数值；把生产者与复制品混扫会让门禁自相矛盾（D0-13） |
| 禁用 token | 由 `data/rules/manifest.json` + 各规则包**数值字段**程序化采集（≥3 位整数及其小数字面量），词边界匹配（左右不得为数字/小数点，避免 `1000` 命中 `10000` 子串） |
| 豁免 1 | 单位换算常量（`units.json` 及其加载路径）——定义性关系，非政策数值 |
| 豁免 2 | 免责声明法律文本（`DISCLAIMER`） |
| 豁免 3 | `Decimal(1).scaleb(-n)` 形式表达的精度位（非字面量小数） |
| 豁免 4 | 标准编号/条款号（公开标识符/元数据）——采集端只采数值字段，天然不采集 |
| 通道探活 | 门禁必须能对"注入的数值"命中（`--selftest` 阳性对照 + `test_zero_literals.py` 探活用例）；M0 初态 token 集为空，不配探活则"通过"可能只是"什么都没扫" |
| 结果 | 命中即 `exit 1`，打印"文件:行号 [token] x次数"（不回显 token 原文之外的敏感串） |
