| # | 日期 | 决策项 | 结论 | 理由 / 影响 |

| D3-1 | 2026-10-13 | **校核阈值属工程判据而非政策数值** | `quality.thresholds` 四项（magnitude / yoy / intensity_min / intensity_max）由 M3 工程定值并标 `verified`；规则包内 `clause.code = null` + 注明"工程筛查阈值（非政策数值）" | 阈值语义：magnitude=单源排放量占全厂合计的占比上限（粗筛，单源档案跳过）；yoy=同一源活动数据跨年度变化率上限；intensity_min/max=比强度（排放量/产量）合理区间。**影响面**：校核路径由全 pending 变全可通过（`check` 退出码由 1 变 0/2）；零字面量 token 集由 7 增至 13 |
| D3-2 | 2026-10-13 | **"平台可查/随机组而异"的配额参数标 `input_required`（新增第三态）** | 门控新增 `status = input_required`：该数值**不由规则包承载**（三行业行业平衡值 BP 仅平台可查、发电调峰修正系数是负荷率 F 的函数）→ 不阻断门控；试算层运行时显式索取，缺失即 `QuotaUnavailable`（退出码 2，**绝不静默取 0/1**） | 用 `pending` 会把"本不由规则包承载的外部输入"误当"未核对的政策数值"，导致配额路径被门控误拦（M1 遗留：配额路径全 pending）。**影响面**：`rules._entry_is_effective` 新增 `input_required` 分支；`plan/04 §五` 配额 schema 增 `derivation` 与 `input_required`；配额路径门控 40/40 可通过 |
| D3-3 | 2026-10-13 | **复合因子单位分隔符单一真相源** | `_per_` 分隔符与拆分函数移到 `units.PER_SEPARATOR` / `units.split_compound_unit`；`calc.py` 复用（保留旧名别名） | 校核层（单位一致性检查）与计算层都要拆 `tCO2e_per_t`；两处各写一份会形成第二份真相。**影响面**：`units.py` 新增公开函数；`calc._split_compound_unit` 降级为转发 |
| D3-4 | 2026-10-13 | **校核分级可降级报出** | 规则的 `level` 是"硬违规"级别；当违规**可被引擎显式换算/可解释**时降一级报出（如"单位同量纲但口径不一致"报 `warning` 而非 `error`） | 避免把"引擎已正确处理"的情形误报为致命错误（假阳性会训练用户忽略告警）。**影响面**：`check` 退出码判据为"是否存在 `error` 级问题"（error→2；仅 warning/info→0） |
| D3-5 | 2026-10-13 | **配额结果双口径（量化 + 全精度）** | `QuotaResult` 同时给 `allocated`/`gap`/`gap_ratio`（量化呈现）与 `*_raw`（全精度对账） | 沿用 `calc` 的 `total` / `total_raw` 模式：呈现口径与对账口径分离，测试用 `*_raw` 逐字段对账真值。**影响面**：`plan/04 §五` 契约补 `*_raw` 字段 |

## 二、豁免口径（零政策字面量门禁的白名单）

`tools/check_zero_literals.py` 扫描范围与豁免（**必须写死，否则门禁刷屏后被运维性忽略**）：

| 类别 | 处置 |
|---|---|
| 扫描范围 | **仅** `code/src/ghg/**/*.py` **与** `code/gui/ghg_gui/**/*.py`（含 docstring 与注释）——引擎与前端源码（GUI 于 M5 纳入，见 D5-3） |
| **不扫**生成器 | `tools/gen_rulesets.py` / `tools/gen_synthetic.py` **不在扫描范围**：生成器是数据文件的生产者（真相源），必然持有模板数值；把生产者与复制品混扫会让门禁自相矛盾（D0-13） |
| 禁用 token | 由 `data/rules/manifest.json` + 各规则包**数值字段**程序化采集（≥3 位整数及其小数字面量），词边界匹配（左右不得为数字/小数点，避免 `1000` 命中 `10000` 子串） |
| 豁免 1 | 单位换算常量（`units.json` 及其加载路径）——定义性关系，非政策数值 |
| 豁免 2 | 免责声明法律文本（`DISCLAIMER`） |
| 豁免 3 | `Decimal(1).scaleb(-n)` 形式表达的精度位（非字面量小数） |
| 豁免 4 | 标准编号/条款号（公开标识符/元数据）——采集端只采数值字段，天然不采集 |
| 通道探活 | 门禁必须能对"注入的数值"命中（`--selftest` 阳性对照 + `test_zero_literals.py` 探活用例）；M0 初态 token 集为空，不配探活则"通过"可能只是"什么都没扫" |
| 结果 | 命中即 `exit 1`，打印"文件:行号 [token] x次数"（不回显 token 原文之外的敏感串） |
